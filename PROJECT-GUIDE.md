# Krish Earn — Combined Project

This single project contains:
- Main user app: index.html
- PWA: manifest.json + sw.js + icon.svg
- User earning/reward demo
- Referral demo
- Wallet/withdrawal demo
- Profile demo
- Admin panel: admin/index.html
- Admin styling and demo controls

Upload the entire extracted folder to one GitHub repository.
The admin demo is available at `/admin/` on GitHub Pages.

IMPORTANT: This is a frontend prototype. Real-money earning/withdrawal requires a secure backend, authentication, database, KYC/privacy compliance, fraud prevention and a compliant payout provider. Demo balances must not be presented as real withdrawable money until those systems are implemented.
