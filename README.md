# Krish Earn

A smart, transparent-glass style earning/rewards app prototype.

## Included
- Mobile-first Home dashboard
- Balance, daily earning and pending rewards
- Quick earning cards
- Referral screen
- Wallet and withdrawal demo
- Profile screen
- Responsive glassmorphism UI
- PWA manifest + service worker
- Offline shell caching
- SVG app icon

## Important
This ZIP is a **frontend prototype**. The earning amounts, withdrawal flow and referral rewards are demo logic only. Before accepting real money or publishing as an earning platform, connect a secure backend/database, authentication, fraud controls, payout/KYC systems, privacy/terms pages and compliant ad/affiliate providers.

## GitHub Pages
Upload all files to a repository root (or a Pages-compatible folder), enable GitHub Pages, then open the Pages URL. Keep `manifest.json`, `sw.js`, `icon.svg`, `index.html`, `style.css` and `app.js` in the same published path.
